# 《离校日》首次公开仓库文件清单

本清单区分公开源码仓库与实际网站。源码仓库包含构建与测试所需文件；Pages 网站只包含工作流新生成的 `dist/`。

## 应公开

| 目录或文件 | 用途 |
| --- | --- |
| `src/`，其中的旧 README 除外 | 游戏页面、样式、剧情数据、状态与本地编辑器源码 |
| `public/` | 作者确认的全部游戏素材，以及 PDF.js 和字体许可证 |
| `scripts/` | 构建校验器、自动化测试、开发插件与本地启动辅助脚本 |
| `.github/workflows/pages.yml` | 测试、构建、仅上传 dist、发布 Pages |
| `package.json`、`package-lock.json` | 安装和构建所需的依赖定义与版本锁定 |
| `index.html`、`vite.config.ts`、`tsconfig.json` | 入口与构建配置 |
| `.gitignore`、`README.md`、`docs/` | 公开范围、运行与更新指南 |
| `启动离校日.cmd` | 原有本地启动入口，使用相对项目位置 |

## 应忽略，仍保留在本地

`output/`、`outputs/`、`.tools/`、`test-results/`、`node_modules/`、`dist/`，以及环境文件、本机 npm 配置、编辑器配置与缓存、日志、临时文件、私钥文件和浏览器测试输出。详细模式见 `.gitignore`。

根目录旧版本说明 `/*.md` 除新的 `README.md` 外全部忽略。`src/content/**/README.md` 是作者维护说明，也只保留本地，其中一份包含原电脑的 Python 路径。未忽略任何游戏 JSON、TS、CSS、正式图片、PDF 或许可证。

整理时 `master` 尚无普通提交、没有远程仓库，Git 索引为空；因此没有需要取消跟踪的文件，也没有暂存内容需要处理。本次没有执行暂存、提交、推送、清理或删除操作。

将来新增忽略规则时必须再次检查 `git ls-files` 和 `git diff --cached --name-only`。忽略规则不会从历史提交或索引中移除已跟踪文件。如果发现真实凭证已入历史，应先撤销凭证并制定清理方案，不能只补 `.gitignore`。

## 已检查的特殊文件

- `src/dev/` 和 `scripts/archive-dev-plugin.mjs` 保留用于以后本地修改。插件 `apply: 'serve'`，编辑器入口受 `import.meta.env.DEV` 控制；生产测试确认无编辑器、无写盘接口请求。插件的令牌由每次运行随机生成，源码没有固定真实凭证。
- `scripts/` 旧浏览器验收脚本含通用 Windows Edge 路径和回环测试网址；PDF 生成脚本含 Windows 字体路径。这些是本地工具路径，不是个人账号路径，不会复制到 dist。发布验收的三个旧脚本已支持 Linux Chromium 及自定义测试网址。
- 游戏的虚构账号、验证码、密码、谜底与未解锁剧情属于必要前端内容，保留不动。公开源码和浏览器开发者工具可以看到它们。
- 未擅自添加开源许可证。公开可读不等于允许他人自由使用游戏剧情和美术；第三方字体与 PDF.js 原许可证必须保留。
- 作者已确认素材可公开。本轮不复核图片中的隐私、不压缩或删除素材。

没有必须再次由作者判断才能构建的特殊文件。上传前仍应审阅实际暂存清单，特别是未来新增的文件。真实凭证扫描未发现常见令牌、私钥格式或个人电脑用户目录路径，不代表扫描能证明所有任意格式秘密均不存在。

## 配置改动

新增工作流；扩充 `.gitignore`；`package.json` 增加 `test:release` 与 `test:pages`。Vite、Hash 路由、存档键、素材、剧情及页面代码保持原状。测试改动仅为生产路径与跨平台执行适配。
